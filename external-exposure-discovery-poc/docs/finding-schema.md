# Suggested Finding Record

- Finding ID
- Target domain association and match type
- Source category and public URL
- Discovery timestamp and discovery method
- Detection reason and matched indicator
- Minimal sanitized evidence excerpt
- Confidence (separate from severity)
- Classification: domain mention / potential exposure / confirmed exposure / unrelated
- Review status: pending / relevant / false positive / confirmed / further investigation
- Reviewer, review timestamp, disposition, and next action

Do not store unnecessary personal data, full leaked documents, credentials, or unrestricted copies of sensitive material. Redact suspected secrets and personal information. A human reviewer must validate findings.
